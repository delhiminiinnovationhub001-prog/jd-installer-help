# JD Installer Help

Common questions and answers for the JD Installer Assistant app, in English and Hindi.

The app downloads `qa.json` from here when it has internet and keeps a copy for offline use.
It only accepts the file if `qa.json.sig` matches it, so a changed file must be signed again by JD Mobility before installers see it.

Do not put passwords, PINs, keys or customer details in these files. This repository is public.
